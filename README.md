# soundsharp-site

Public pages for the Sound Sharp iOS app, served by GitHub Pages:

- `/` — landing page
- `/support` — App Store Support URL
- `/privacy` — App Store Privacy Policy URL
- `/terms` — Terms of Service (Terms of Use link for the subscription)

The privacy and terms text must match the in-app screens in the `soundsharp` repo
(`app/privacy.tsx`, `app/terms.tsx`). Change both together.
